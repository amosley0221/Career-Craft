      5. Technical skill sprint menu

      Use this to choose the Month 2 skill track. The goal is not to master everything; it is to build enough ability to create the portfolio project.

      Track A: AI-assisted software builder

      Best match for UNC Charlotte AI-Assisted Software Engineering.

      • 1HTML/CSS/JavaScript basics
      • 2GitHub and project README habits
      • 3Build a local-storage web app
      • 4Use AI tools to debug, refactor, and document code

      Track B: MIS / business systems

      Best match for ECU MIS and business analyst roles.

      • 1SQL basics: tables, filters, joins, grouping
      • 2Business requirements and process mapping
      • 3Dashboard or spreadsheet model
      • 4Write a short systems-analysis case study

      Track C: balanced bridge

      Best if you are still deciding between software and MIS.

      • 1HTML/CSS/JS for the front end
      • 2SQL for data and requirements
      • 3One project combining scoring, data, and a clear user problem
      • 4A README that explains the business value

      7. Decision rules for the end of 90 days

      These rules prevent overthinking. Update them if your priorities change.

      • Choose UNC Charlotte AI-Assisted Software Engineering if the transfer path is feasible, coding feels hard but exciting, and you are willing to build projects consistently.
      • Choose ECU MIS if the business/tech bridge feels more sustainable, completion odds matter most, and you prefer systems, analysis, project management, or IT leadership over daily coding.
      • Choose another option if another online AI/CS/MIS program beats both on transfer fit, cost, flexibility, completion odds, and career alignment.
      • Delay the start term if the math, credit, GPA, application, or financial-aid reality makes rushing risky. Use the extra term for prerequisites, portfolio work, and advisor confirmation.
