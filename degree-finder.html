Project purpose

This project turns your degree decision into a portfolio piece. It shows that you can identify a real-world problem, model data, build an interactive tool, and explain recommendations clearly.

Portfolio angle: "I built a decision-support web app to compare academic pathways using weighted criteria, eligibility checks, and personalized recommendations."

Portfolio Story

How this becomes a strong portfolio project

Problem

Choosing a degree path is difficult because requirements, career outcomes, personal readiness, and life constraints are scattered across different sources.

Solution

AI Degree Finder puts those inputs into one decision-support interface with editable data, weighted scoring, readiness checks, and explainable recommendations.

Why it matters

The app demonstrates practical software thinking: data modeling, user inputs, state persistence, scoring algorithms, UI design, and source-based decision support.

Resume bullets you can eventually use

  • Built a browser-based decision-support tool using HTML, CSS, and JavaScript to compare academic pathways using weighted scoring and readiness checks.
  • Implemented localStorage persistence, JSON backup/import, dynamic form rendering, and print-to-PDF export for a self-contained client-side app.
  • Designed an explainable recommendation engine that combines user goals, transfer requirements, and career-fit criteria into ranked results.

Technical Architecture

What this project demonstrates

Data model

Program objects, user profile inputs, weights, eligibility requirements, and career role metadata.

Scoring engine

Weighted program score + readiness score + preference fit + risk flags.

State management

Automatic local saving and JSON export/import so decisions can evolve over time.

UI rendering

Dynamic program table, ranking cards, readiness panels, advisor questions, and summary stats.

Export workflow

Print-friendly CSS enables browser save-to-PDF for snapshots.

Next AI layer

Future version can add natural-language explanations, transcript parsing, or a chatbot-style advisor.
